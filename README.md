# 🌸 Tienda Cosméticos & Perfumería

Aplicación web para la gestión, exhibición y comercialización de productos de cosmética y perfumería. Catálogo dinámico con consulta directa por WhatsApp para coordinar la compra.

## 🚀 Características Principales
- **Catálogo Dinámico**: Sincronización en tiempo real con base de datos en la nube para la carga y visualización de productos.
- **Detalle de Producto**: Vista avanzada con galería de imágenes, descripción detallada y precio.
- **Consulta Directa a WhatsApp**: Cada producto tiene un botón para consultar o comprar directamente por WhatsApp, sin pasos intermedios.
- **Panel de Administración**: Gestión de productos (agregar, editar, eliminar) protegida con clave de acceso.
- **Diseño UI/UX**: Paleta en tonos rosa/rose, tipografía cuidada y transiciones suaves.

## 🛠️ Tecnologías Utilizadas
- **Frontend**: React.js (Vite), React Router DOM.
- **Estilos**: Tailwind CSS.
- **Base de Datos / Backend**: Firebase (Cloud Firestore).
- **Imágenes**: Cloudinary.
- **Control de Versiones**: Git & GitHub.
